# Changelog

## 0.1.0 — 2026-10-01

First distributable host-only Desktop prompt correction.

- Detect the actual desktop host entry instead of inferring a browser surface from package names, profile names, or a loopback URL.
- Replace the two known inherited Web/source templates through the official assembly waterfall.
- Explain native-window targeting, ASAR virtual paths, mirror verification, separate update paths, and active-task refresh hazards.
- Preserve tools, permissions, model variables, unrelated sections, and intentional complete prompts.
- Refuse to rewrite unknown/future/custom prompt templates.
- Move metadata-only best-effort diagnostics outside the installed package; export only sanitized status metadata rather than prompt text, paths, or session details.
- Split portable unit tests from explicitly configured real-runtime integration tests.
- Add bilingual documentation, localized plugin metadata, exact verified host peers, and release checks.

### Compatibility / known limitations

Verified on Windows DeepSeek Harness Desktop 0.2.0-rc.2. Other native operating systems and future versions require re-verification. Diagnostics reflect assembly-hook execution, not proof that a provider consumed the prompt. This package does not automatically restart the app or guarantee model compliance with its instructions.
